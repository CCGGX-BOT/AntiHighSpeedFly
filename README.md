# AntiHighSpeedFly —— Paper 高版本反「高速飞行」外挂插件

纯 **Paper API**（事件级，不依赖 ProtocolLib）的反高速飞行（SpeedFly / FastFly）插件。
**没有普通限速，也没有测速逻辑**——核心是**物理一致性预测**：用游戏自身的水平运动物理
从玩家上一次被服务端接受的速度出发，预测本 tick 应有的位移，再与实际位移对比。
偏差（残差）超过容差 = 物理上不可能的运动 = 违规。

正常玩法完全不受影响：创造飞行、鞘翅（含烟花喷射）、疾跑、跳跃、冰面滑行、游泳、
激流三叉戟等都在物理模型的合法预测范围内。

## 为什么不用「测速」逻辑

普通测速（速度 > X 就处理）有两个致命问题：要么误杀合法高速玩法（鞘翅/创造疾跑飞行），
要么被外挂「贴边」绕过（把速度调到刚好低于阈值）。本插件根本**不比较速度大小**，
而是验证**运动是否符合它自身的物理规律**：

| 状态 | 物理模型预测规则 | 外挂如何被识破 |
| --- | --- | --- |
| 空中 | 水平速度每 tick 必须 ×0.91（阻力）+ 微量空中操控 | 恒定高速飞行无法维持：残差 ≈ 0.09×速度 |
| 地面(有输入) | 速度必须向「步行×疾跑×速度药水」目标收敛 | 恒定高于目标速度 → 持续残差 |
| 地面(无输入) | 必须按脚下方块摩擦衰减（普通 0.546 / 冰面 0.989 / 灵魂沙 0.4） | 无输入却保持高速 → 残差 |
| 创造飞行 | 速度必须向 flySpeed 属性推导的目标收敛（疾跑×2） | 恒定超出目标速度 → 残差 |
| 游泳 | 低于目标向目标接近，高于目标只能按阻力 0.8 衰减 | 恒定高速游泳 → 残差 |
| 鞘翅 | 水平分量只按 0.99 阻力衰减（俯冲/拉起时速度向量随视角旋转，水平随总速度合法增长）；3D 总速度超过 80 m/s 必须衰减 | 恒定超高速滑翔违反「末端速度衰减」规则 |
| 坐骑 | 不检测（速度由坐骑实体决定） | — |

速度的「上限」是物理模型**自然推导**出来的（例如空中恒定 1 b/t 必然产生 0.09 b/t
残差，超过 0.08 容差即违规），**配置里只有「残差容差」这一个模型误差参数，没有任何
最大速度数字**。

## 多信号与防误报体系

- **真实按键输入**：接入 Paper `PlayerInputEvent`，区分「主动加速」与「惯性滑行」，
  地面/空中模型才能精确预测；
- **状态跃迁宽限**：落地/起跳/起飞/入水后 150ms 不检测，吸收模型切换瞬时误差；
- **服务端速度宽限**：击退/TNT/激流等由服务端主动施加的速度（`PlayerVelocityEvent`），
  300ms 内完全跳过，之后 1s 内容差放大 1.6 倍吸收衰减期；
- **传送宽限**：任何传送（`PlayerTeleportEvent`）后 200ms 不检测；
- **烟花喷射宽限**：鞘翅使用烟花（`PlayerInteractEvent`）后 400ms 不检测；
- **恶意包防御**：NaN/Infinity 坐标直接 +100 怀疑度；
- **怀疑度梯度惩罚**：残差按超出比例累计 → 警告 → 取消移动(拉回) → 回退最近安全位置
  （冷却 1.5s）→ 踢出；无违规时每秒自然衰减，不会永久标记。

## 构建

```bash
mvn -DskipTests package
# 输出: target/AntiHighSpeedFly.jar
```

## 环境要求

- **Paper 1.21+**（1.21.1 ~ 1.21.x 均兼容；如使用其他版本请同步修改 `pom.xml` 中的 paper-api 版本）
- **Java 21+**（Paper 1.21 运行要求）

## 安装

1. `mvn package` 得到 `target/AntiHighSpeedFly.jar`
2. 放入服务端 `plugins/` 目录，重启服务端（或 `/reload confirm`）
3. 生成默认配置后按需编辑 `plugins/AntiHighSpeedFly/config.yml`

## 命令

| 命令 | 说明 |
| --- | --- |
| `/antifly reload` | 重载配置 |
| `/antifly toggle` | 启用/禁用检测 |
| `/antifly info` | 查看运行状态与当前参数 |
| `/antifly reset <玩家>` | 重置某玩家怀疑度 |
| `/antifly test <玩家>` | 开启/关闭该玩家实时调试面板（显示 res/tol/over/sus） |

## 权限

| 权限 | 默认 | 说明 |
| --- | --- | --- |
| `antihighspeedfly.bypass` | false | 免于检测 |
| `antihighspeedfly.alert` | op | 接收疑似高速飞行警报 |
| `antihighspeedfly.admin` | op | 使用管理命令 |

## 参数调优建议

- 误报偏多（高延迟服务器）：调大 `physics.residual-tolerance-*`、`suspicion.require-consecutive-violations`
- 漏掉高速飞：调小 `physics.residual-tolerance-air` / `residual-tolerance-ground`
- 外挂贴边：调小 `suspicion.warn-at / setback-at`

## 已知边界（设计取舍）

- **坐骑**（马/船/矿车）不检测——坐骑速度由坐骑实体决定，属另一类问题
- **鞘翅 3D 总速度 ≤ 80 m/s (4 b/t) 的恒定滑翔**模型允许——俯冲加速、烟花喷射、
  拉起机动全部在这一物理极限以内，属于合法玩法；总速度超过 80 m/s 后必须按阻力
  衰减，否则判定违规（v1.1.1 起）
- **空中低于 ~1.2 b/t（24 m/s）的恒定飞行**在残差容差内——低于该值更接近「低速飞」，
  与"只防高速飞行"的定位一致；需要更严可调小 `residual-tolerance-air`
- 不拦截传送类外挂（瞬移）——那是另一类问题，本插件专注高速移动

## 更新日志

### 1.1.1（当前）
- **修复**：玩家使用鞘翅向下俯冲（含俯冲后拉起）时被误判为高速飞行的问题。
  原因：旧模型对鞘翅水平速度强制「向 32 m/s 目标收敛、超过后必须衰减」，但俯冲时
  总速度被重力加速、速度向量随视角旋转，水平分量会合法增长，从而产生大量残差。
  修复：水平分量改为只按 0.99 阻力预测；新增 3D 总速度末端速度规则
  （> 80 m/s 必须衰减）拦截真正恒定超高速的滑翔外挂；鞘翅容差放宽至 0.18
- 版本号升至 1.1.1

### 1.0.0
- 初始版本：物理一致性检测（无测速逻辑）
